# Care Scribe — synthetic demo

A playable demo of Care Scribe, a charting concept for nurses.

- **Every chart is fictional.** The demo runs entirely in your browser on synthetic data. Nothing is sent to any server.
- Quick-record workflow: UHC-format assessment template, initial/annual assessment scripts, documentation formats (DAR, SOAP/SOAPIE, PIE, CBE, narrative), a height/weight → BMI calculator, exports (PDF/Word/text/JSON) and native share.
- Independent templates; not affiliated with or endorsed by any health plan or vendor.
- This repository contains **built files only** — it is a temporary demo host, not the product source.
- Not approved for real patient information.
